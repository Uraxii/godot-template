# Index

- `.github/`: issue forms, the PR template, and CI workflows (MegaLinter, gdtoolkit, GUT tests, PR title check).
- `scripts/`: host tools. `setup-project.sh` creates the Godot project and fetches Godot; `run-tests.sh` runs the GUT tests; `test-setup-project.sh` checks both.
- `src/`: the Godot project. `scripts/setup-project.sh` creates it and rewrites this index to list its folders.
- `CLAUDE.md`: how work is planned, tracked, and shipped here.
